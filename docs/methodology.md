# 方法论说明（面试备用）

> 本文档把工具包背后的统计/运筹方法讲清楚，供研究复现与面试讲解使用。

## 1. DEA（数据包络分析）

### 1.1 基本思想
给定 N 个决策单元（DMU），每个单元有 m 个投入、s 个产出。DEA 不求参数函数形式，
而是通过**线性规划**为每个单元构造一个"虚拟标杆"：把其他单元按权重 λ 加权组合，
比较该单元相对标杆的投入冗余 / 产出不足程度，从而得到效率得分（0~1，1 为有效）。

### 1.2 CCR 模型（规模报酬不变，CRS）
产出导向包络形式（本文工具包默认口径）：

```
max  φ
s.t. Y λ ≥ φ · y_k      （虚拟标杆产出不低于 φ 倍被评单元产出）
     X λ ≤ x_k          （虚拟标杆投入不超过被评单元投入）
     λ ≥ 0
```

效率 = 1 / φ。φ 越大说明被评单元"越不够产出"，相对越低效。

投入导向同理，目标变为 `min θ`，效率 = θ。

### 1.3 BCC 模型（规模报酬可变，VRS）
在 CCR 基础上增加凸性约束 `Σλ = 1`，剥离规模效应，得到纯技术效率。
规模效率 = CRS 效率 / VRS 效率。

### 1.4 两阶段 DEA
把生产链拆成两段：

```
阶段一：X1（资源禀赋投入） ──► Z（中间产出，如数字基础设施）
阶段二：Z（作为投入）     ──► Y2（最终产出，如创业活跃度）
```

本文工具包对两阶段**独立测算** CCR/BCC 效率，系统效率 = E1 × E2。
该分层思想与 Lafuente, Ács & Szerb (2024, JSBM) 的网络 DEA 一脉相承。

## 2. 面板门槛回归（Hansen 1999）

### 2.1 问题
怀疑解释变量 x 对被解释变量 y 的驱动存在**门槛非线性**：存在临界值 γ，
x 的斜率在 q ≤ γ 与 q > γ 两段显著不同。

### 2.2 模型
```
y_it = μ_i + β1·x_it·I(q_it ≤ γ) + β2·x_it·I(q_it > γ) + ε_it
```

### 2.3 估计步骤
1. **within 变换**：对每个实体 i，用观测值减其组内均值，消除个体固定效应 μ_i；
2. **网格搜索**：在门槛变量 q 的取值区间内取候选 γ，逐个做分段 OLS，记录残差平方和 SSE(γ)；
3. **取最小 SSE 的 γ\*** 作为门槛估计；
4. 在 γ\* 下重新拟合，得到两段斜率 β1、β2。

（完整显著性检验需用似然比统计量 + 自助法构造临界值，本文工具包给出点估计，
显著性检验可作为进阶扩展。）

## 3. 分位数回归（Koenker & Bassett 1978）

普通 OLS 只刻画"均值"上的条件关系；分位数回归在因变量的不同分位点 τ 上分别
最小化非对称绝对损失，刻画解释变量在**分布不同位置**的异质效应。

常用于回答："某驱动因素在低效率组与高效率组的边际作用是否相同？"——若系数随
分位点单调变化，则说明存在分布异质性，需差异化施策。
